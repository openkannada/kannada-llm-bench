# Security

kannada-llm-bench downloads pinned datasets, tokenizers and model weights and runs them locally. If you find a security problem, such as a download that is not checked against its pin, or code that runs something it should not, email prasad@luminik.io instead of opening a public issue. Include the commit and the steps to reproduce it.

Ordinary bugs and wrong answer keys go in [GitHub issues](https://github.com/openkannada/kannada-llm-bench/issues).
